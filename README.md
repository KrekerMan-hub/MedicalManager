\# Medical Manager



Учебный проект на Python для управления пациентами.



\## Возможности



\- добавление пациентов

\- хранение данных пациентов

\- работа с отделениями

\- сохранение данных в JSON



Проект развивается в рамках изучения Python.



Проект опубликован на GitHub из ветки conflict-a.



Изменение сделано в test-branch.
